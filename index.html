Recordatorios

Revisita usa el calendario de tu teléfono para avisarte. Al guardar una revisita con fecha, se abre el calendario para añadirla con una alarma.

Activa avisos en este dispositivo para recibir una notificación 5 minutos antes de cada revisita con hora, incluso con la app cerrada. Se envían el nombre y la hora al servicio de avisos.

Apple no permite que una página instale la app automáticamente. Haz estos pasos:

1

Toca el botón Compartir del navegador (cuadrado con flecha hacia arriba).

2

Elige “Añadir a pantalla de inicio”.

3

Toca “Añadir” para terminar.
